9. Pseudocode – FCFS

Sort processes according to arrival time

time = 0

For each process:
    If time < arrival time:
        time = arrival time

    time = time + burst time

    completion time = time

    turnaround time = completion time - arrival time

    waiting time = turnaround time - burst time

10. C Program – FCFS

#include <stdio.h>

int main() {
    int n, i, j, at[20], bt[20];
    int ct[20], tat[20], wt[20], time = 0;
    int temp;
    float avgTAT = 0, avgWT = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    for(i = 0; i < n; i++) {
        printf("Enter arrival and burst time: ");
        scanf("%d%d", &at[i], &bt[i]);
    }

    for(i = 0; i < n-1; i++) {
        for(j = i+1; j < n; j++) {
            if(at[i] > at[j]) {
                temp = at[i];
                at[i] = at[j];
                at[j] = temp;

                temp = bt[i];
                bt[i] = bt[j];
                bt[j] = temp;
            }
        }
    }

    for(i = 0; i < n; i++) {
        if(time < at[i])
            time = at[i];

        time += bt[i];

        ct[i] = time;
        tat[i] = ct[i] - at[i];
        wt[i] = tat[i] - bt[i];

        avgTAT += tat[i];
        avgWT += wt[i];
    }

    printf("\nP\tCT\tTAT\tWT\n");

    for(i = 0; i < n; i++) {
        printf("P%d\t%d\t%d\t%d\n",
        i+1, ct[i], tat[i], wt[i]);
    }

    printf("Average TAT = %.2f\n", avgTAT/n);
    printf("Average WT = %.2f\n", avgWT/n);

    return 0;
}

11. FAQs

1. What is CPU scheduling?
It is the process of selecting a process from the ready queue for CPU execution.

2. What is FCFS?
First Come First Serve executes processes in arrival order.

3. What is SJF?
Shortest Job First selects the process with the smallest burst time among arrived processes.

4. What is Round Robin?
It allocates CPU time to each process using a fixed time quantum.

5. What is completion time?
The time at which a process finishes execution.

6. What is turnaround time?
TAT = Completion Time - Arrival Time.

7. What is waiting time?
WT = Turnaround Time - Burst Time.
